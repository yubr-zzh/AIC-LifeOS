# LifeOS UI 优化阶段记录

目标：让 LifeOS 更像面向日常使用的「AI + 日记 + 记忆」产品，把工程实现细节保留在高级区域，不让它主导普通用户的第一视线。

## 阶段计划

1. **收敛导航与入口**：主导航围绕今天、对话、计划、记录、我的记忆组织；系统后台不作为日常入口。
2. **重做首页主流程**：突出“记录今天 / 和 LifeOS 聊聊 / 推进下一步”之一的主动作，减少伪统计和工程状态。
3. **降低对话工程感**：默认隐藏 Planner、Agent、Trace、Event Bus 等内部术语；涉及副作用时仍明确显示确认和风险。
4. **重做 Memory 用户界面**：用“我的记忆、关于我、项目、待确认”等语言呈现长期认知，显示依据并支持修正、撤回。
5. **高级设置隔离**：API 地址、数据库、事件、运行轨迹和调试面板集中到高级设置/诊断区域。
6. **重构对话体验**：让对话、新建、历史回找成为一个连贯的聊天工作区。
7. **浏览器验收**：检查桌面、窄屏、空数据、加载、错误与键盘操作。

## 当前进度

### 阶段 1：导航与入口（已完成）

- 已增加“我的记忆”日常入口，并连接到 Memory 页面。
- 已将 Memory 页签从 User/Project/Candidates 等工程术语改为用户语言。
- 已从聊天主界面移除 Runtime Rail；系统后台仍保留为可通过 hash/高级入口访问的诊断页面。
- 主导航收敛为“今天 / 和 LifeOS 聊聊 / 计划 / 记录”，系统后台不再占据日常导航。
- 计划与回顾、日记与心得、反馈与历史回看分别归入“计划”和“记录”入口；原有 hash 路由仍兼容。
- 已隐藏系统后台的日常导航项和页头同步状态，避免工程信息占据主流程；诊断从“数据与隐私”中按需进入。

验收：当前 `npm run typecheck`、`npm run build`、`git diff --check` 通过。浏览器自动化对本轮最新 UI 的检查尚未完成，不能据此标记通过。

### 阶段 2：首页主流程（已完成第一轮）

- 首页移除虚构的任务、完成率、生活节奏和鼓励语，改为展示真实的今日计划与最近记录。
- 空数据、加载中和读取失败都有明确状态；首要动作是与 LifeOS 聊聊，次要动作是写计划。
- 首页日期及保存日期使用本地日历日期，避免 UTC 时区导致日期错一天。

### 阶段 3：降低对话工程感（已完成第一轮）

- 隐藏对话中的路由策略开关、运行轨迹、模型/Trace 标识和内部规划置信度。
- 对话主要文案改为面向用户的中文表达；执行相关工具请求仍保留状态展示，不弱化操作边界。
- 设置中的处理偏好仍可调整，诊断信息保留在显式入口后。

### 阶段 4：Memory 主界面去工程化（第一轮完成）

- 将英文空状态、审批按钮、内部状态名改为用户可理解的中文。
- 记忆卡片默认展示主要认知内容；完整结构化内容折叠到“查看完整内容”，来源依据也按需展开，仍保留查看依据的能力。
- 画像不再直接展示 active、版本号、数据模式等内部实现信息；空画像状态说明需要先采纳记忆。
- 保留修正、撤回及用户确认语义；更改/撤回影响后续召回，但不删除原始来源记录。
- 原始 `memory.md` 页面改称“记忆文件”，并说明导入是新增，不会覆盖已有记忆。

### 阶段 5：对话工作区重构（第一轮完成）

参考主流对话产品的共同模式：主聊天区域聚焦当前交流，历史按最近活动组织并支持搜索，新建对话入口明确；Gemini 还提供置顶、重命名和删除历史对话的管理方式。本轮按 LifeOS 当前数据能力先实现搜索/时间分组/空白新对话，不新增尚无后端模型支持的置顶、重命名或删除操作。

- 新建对话不再插入“LifeOS 已连接”等技术提示消息，而显示欢迎态和可选开场建议；点击建议只填入输入框，不会自动发送。
- 桌面端采用历史列表 + 当前会话双栏；窄屏历史改为可打开/关闭的侧面板。
- 历史列表保留按最近交流时间分组和全文搜索，预览改为用户可读内容；增加无结果提示。
- 聊天消息改为更清晰的用户气泡与助手正文布局；输入区固定在对话底部，显示发送快捷键；IM 输入组合期间按 Enter 不会意外发送。
- 工具调用保留状态与安全信息，详细参数默认折叠。
- 当前历史会话及新建操作仍由前端本地保存；现有 `/chat` API 请求没有携带 conversation/session id，因此本轮没有宣称后端已有真正独立的多会话上下文。后续应把会话 ID 接通到 API/Agent runtime 后再验收跨轮上下文隔离。

调研参考：[ChatGPT 历史搜索](https://help.openai.com/en/articles/10056348-how-do-i-search-my-chat-history-in-chatgpt)、[ChatGPT 新建对话](https://help.openai.com/en/articles/9125172-the-chatgpt-home-page)、[Gemini 最近对话管理](https://support.google.com/gemini/answer/13666746?hl=en-IE)、[Claude 项目与独立对话空间](https://support.anthropic.com/en/articles/9517075-what-are-projects)。
